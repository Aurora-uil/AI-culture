# 元代篇正式人物立绘美术设定 V1

## 统一生产规格

- 用途：网页视觉小说单人对白立绘。
- 画幅：竖版全身，人物与双脚完整，轮廓四周保留安全边距。
- 背景：真实透明通道，不绘制场景、文字、标签或装饰框。
- 统一风格：细墨线描、克制的矿物色、旧纸颗粒、略扁平的古画空间感；轮廓必须适合叠加在深浅不同的剧情背景上。
- 时代边界：1345 年居庸关过街塔施工现场；服装与工具以元代劳动者和跨地域知识工作者的合理重建为准。
- 禁止项：清代服饰、贵族皮裘、军甲、玄幻法器、现代物件、未经校对的古文字、演员脸、英雄化站姿。

## 陈砺｜施工协调者

- 年龄感：36–42 岁。
- 外形：结实、晒黑、前臂有力量，衣服沾石粉，眼神疲惫但直接。
- 性格可视化：可靠、务实、略固执；不是粗鲁反派，也不是英雄。
- 服装：赭褐色粗布交领短袍，烟蓝色包边与腰带，卷袖，深灰宽裤，绑腿和旧靴，简单布头巾。
- 道具：小型石工锤、木尺或粉笔标记，均自然下垂，不作战斗姿势。
- 姿态：三分之二侧身、微微前倾，像在争论中认真听对方说话。

## 帖木儿｜文字校核者

- 年龄感：30–38 岁。
- 外形：清瘦、常年奔走留下轻微风霜，目光集中、表情克制。
- 性格可视化：警惕细节、敢于质疑，也能够承认自己只掌握部分信息。
- 服装：靛青与灰蓝色的元代朴素长袍，便于工地行走的窄袖内层和旧靴；装束体现跨地域工作者，而不把人物塑造成民族符号。
- 道具：无可辨识文字的折叠校样或空白纸卷、一支细木指示杆。
- 姿态：侧身审视纸张，另一只手做小幅解释动作；避免教师式高位手势。

## 桑结｜问题重构者

- 年龄感：38–46 岁。
- 外形：沉静、风尘感较轻，观察多于表态；脸部轮廓温和但眼神锐利。
- 性格可视化：不承担“老师”角色，善于把“谁对”转换为“是否在回答同一个问题”。
- 服装：铁锈红、深褐、岩灰的朴素分层袍服与短披肩；不使用宗教法器、夸张礼服或身份象征。
- 道具：两张相互错开的空白折纸或一根测量绳，体现版本重叠与关系判断。
- 姿态：身体放松，一手压住两张纸的交界，像刚提出一个让所有人停下来的问题。

## 现场负责人｜年长工匠

- 年龄感：55–65 岁。
- 外形：肩背结实但已有疲态，额纹深，手掌粗糙，带自然灰发。
- 性格可视化：时间压力下的实际权威；关心工程能否继续，不是官员或武人。
- 服装：深褐或灰蓝粗布长衣、旧的无袖工作坎肩、朴素布帽、工具腰带；不穿华贵皮毛与佩刀。
- 道具：木制计筹板或卷起的空白工单。
- 姿态：一手持工单，另一手自然指向工作区域；视线略抬，像刚看完天色后催促定案。

## 界面适配要求

- 四人的头部视觉高度、全身比例和脚底基线保持一致，避免对白切换时人物忽大忽小。
- 陈砺的轮廓偏宽、帖木儿偏窄、桑结偏垂直稳定、负责人偏方正，确保只看剪影也能区分人物。
- 所有道具靠近身体，不得大幅横向伸出，以免在移动端被裁切或遮挡对白框。
- 正式文件建议使用：`chen-li-v2.png`、`temur-v2.png`、`sangjie-v2.png`、`foreman-v2.png`。
