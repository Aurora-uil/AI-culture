# 《同心千年》当代篇剧情重构 V4

## 一、这次重构解决什么

旧版把核心冲突压在“未经许可使用原作—重新签共创单—公开体验上线”。权利边界本身正确，但民族关系只存在于结尾总结中：角色大多在处理文件、接口和发布事故，观众很难看见羌绣如何与灾后重建、本地生活、不同民族参与者和跨地区社会联系发生关系。

V4 将章节改为《一针之后，二十四封回信》。叙事不再问“AI能不能生成”，而连续追问三件事：

1. 灾后羌绣恢复是单向救助，还是公共支援与本地主体行动共同完成？
2. 不同地区、民族和职业的人一起学习时，怎样形成联系而不冒充同一种身份？
3. 一件作品怎样从本地出发、在远方得到独立回应，再把新的问题带回原作者身边？

AI只在第三问中承担转写、检索和关系整理，不再担当主题中心。

## 二、同心主题的因果链

```text
国家与社会提供保护、培训和恢复条件
→ 当地妇女学习、生产、交活并逐步授艺
→ 合作社、企业、市场与消费者让技艺进入持续生活
→ 跨县、跨地区、汉藏羌等不同民族参与者共同研修
→ 羌绣创作者以具体作品和问题主动发出交流
→ 远方学生以自己的生活、材料和技艺作出回应
→ 作品和问题回到工坊，原作者再次回答
→ 共同体由持续往返形成，而不是由统一外观证明
```

“同心”因此有四个可见条件：各方都有行动；行动彼此需要；每个人的位置和边界清楚；联系可以返回而非一次性消费。

## 四、三条结局不是好坏题

### 先做档案展，不寄材料

保护史实准确与创作者当前负荷。学生能够看见、提问，但没有作品返回；系统明确记录为“观看与发问”，不冒充共同创作。

### 先寄问题卡，一个月后结对

学生先决定想问什么，创作者再自主选择回应。它牺牲进度和整齐的首发效果，换取双方共同定义交流起点。

### 先做八组一对一，十六校延期

先保证八条关系至少完成一次寄出、回应和再答复。规模最小、等待最长，但每条线两端都有人，也最能抵抗“用复制数量证明同心”的诱惑。

## 五、人物不承担民族符号功能

- 阿若是羌族虚构个体和合作社青年教师。她能解释自己的作品与教学，不能替所有羌绣创作者发言。
- 顾槿是汉族虚构个体和交互设计师。她的弧线不是“外来技术者被教育”，而是从相信标准化能扩大参与，转为理解技术应帮助具体关系持续。
- 拉姆是藏族虚构个体和州内职校电商学生。她通过订单、署名、回邮和页面字段参与协作，但不会因此获得羌绣纹样的统一解释权。
- 小满是远方虚构学生。她的剪纸与羌绣发生关系，但不会被改名为“海洋羌绣”，避免把一次体验写成身份或技艺占有。

## 六、史实与虚构边界

公开资料可以支持：羌绣列入国家级非遗名录；灾后开展非遗保护、技能培训、就业帮扶、居家生产和市场连接；当代存在跨县培训以及不同地区、民族学员共同研修。

剧情必须明确标为虚构：二〇〇八年资料箱、阿若等人物、二十四所学校、所有作品名称、试寄回信和三条项目结局。不得为真实灾后参与者补写私人记忆，不得从图片推断纹样寓意，也不得把角色意见扩大为民族共同意见。

## 八、验收标准

1. 玩家不读结尾，也能通过前七场操作说出至少三类不同主体及其行动。
2. 所有关键选择都改变关系如何继续，而不只是改变文案评价。
3. AI统一纹样必须退出项目，AI只能整理经过确认的内容和往返关系。
4. 学生回件必须保留自身材料、生活经验和作品类别，不能被重命名为羌绣。
5. 结尾的民族交融结论必须能从“支援—生产—学习—回应—再回应”的已完成证据链推出。
