# 《同心千年》当代篇结构深化 V3

## 一、V2 为什么仍显得短和抒情

V2 已经建立“越界草案—原作退出—三方共创”的正确主线，但场景常在人物表达立场后立即进入答题。很多台词承担的是主题总结，而不是推动事件：阿若说明边界、顾槿承认问题、周禾概括共同创造。结果是人物观点正确，却缺少类似清代篇“受潮名册—先发粮—路线纠错—物资到岸—共同写簿”的连续物件和责任链。

V3 因此不再靠增加抒情段落延长篇幅，而加入能够跨场传递的六组状态：

1. 四百零七名预约观众与明确开场时间；
2. 十六张越界变体、生成接口删除请求与最终回执；
3. 原作、练习布和阿若为本项目新画的三段节奏纸；
4. V17 自动补帧失败记录、V18 停顿优先版本和三方停机权限；
5. 场地方临时增加的直播切片与截图下载要求；
6. 次日另一传统手工艺社群发来的合作邮件。

这些状态迫使人物持续做事，而不是重复解释价值观。

## 二、参照清代篇采用的结构

清代篇有效的地方不是历史背景更宏大，而是每场都有“眼前必须处理的对象”：名册、粮食、路线、数字、牲畜、牧地和责任簿。当代篇对应改为：

```text
错误发布文件
→ 操作日志与接口留存
→ 练习布上的失败试针
→ 被退回的展签
→ 新作节奏纸与数据范围
→ 三方共创单
→ 失败的联调版本
→ 临时直播与下载需求
→ 现场暂停记录
→ 下一次合作模板
```

每一项既是剧情道具，也是下一场的进入条件。

## 四、台词调整规则

- 删除“共同创造意味着……”式轮流发言，改为角色报告事实、提出方案、拒绝具体请求或承担责任。
- 一条对白只完成一个主要动作，尽量包含时间、文件、物件、参数、人数或下一责任人。
- 顾槿不再迅速认错，她必须逐步发现：署名遗漏、默认留存、只复制路线、自动补帧和临时传播分别是不同问题。
- 阿若不仅说明边界，还制作节奏纸、规定动作数据范围、参与联调、持有停机键并处理观众提问。
- 周禾不发表抽象伦理结论，主要工作是封存、标注待核、分配权限、保存失败版本和拒绝新增用途。

## 五、“同心”如何由事件体现

### 不是所有人说同一种话

三人对项目的优先级始终不同：阿若关注作品与手作判断，顾槿关注体验与技术运行，周禾关注记录与后续责任。结局没有消除这些差异。

### 不是共享同一批文化素材

原作始终不进入生成。真正进入共同成果的是三方在本次合作中新做的内容，而且用途分开记录。

### 是共同处理对方不能独自解决的问题

- 阿若能决定手作内容，但需要顾槿把身体节奏转成可被远处观众理解的交互。
- 顾槿能运行程序，但不能替阿若定义作品，也不能独自扩大传播范围。
- 周禾能建立流程，但不能替两位创作者作创作判断。
- 现场暂停时，三人分别承担说明、修复和发布控制，缺少任何一人都无法继续。

### 最终升华落在可复制的方法

下一项目不能直接套用阿若的节奏，却可以复用五个空字段：当地参与者、具体作品、允许用途、新增贡献、暂停与撤回方式。不同民族和地区的技艺不需要变成同一种图案，也能在平等规则中互相认识、共同工作。

## 六、篇幅与体验目标

- 固定对白由37条增加至62条，分支场景每条路线另含4条结果对白，单次完整路线共66条。
- 体验时长由约30分钟调整为35—40分钟。
- 十场均有明确时刻、场所、任务和留给下一场的责任。
- 仍保留史料确证、研究解释、尚未确认与剧情虚构四层复盘，新增内容不冒充真实传承人口述。
