# 六章文物剧情锚点 V1

本文件记录六章从“宏观历史叙事”转向“具体对象推动剧情”的统一设计。剧情锚点必须是已经进入内容库的具名文物、遗存或经授权的当代作品；玩家的选择改变记录方式，不改变历史事实。

| 章节 | 剧情锚点 | 核心冲突 | 必须守住的边界 |
|---|---|---|---|
| 汉代 | “五星出东方利中国”锦护膊 | 错误展签把织锦直接归因于张骞 | 它是后世交通网络的物证，不是张骞的直接遗物 |
| 北魏 | 元羽墓志 | 策展人想用一方墓志概括整个北魏 | 墓志支持墓主个案，不能单独代表整个社会 |
| 唐代 | 《步辇图》 | 文成公主与事件相关，却不在画中 | 历史画不是现场照片，画外关系需由其他来源连接 |
| 元代 | 居庸关云台六体文字题刻 | 拓片字形与空间证据指向不同位置 | 文字、语言、文本和人群身份不能互相替代 |
| 清代 | 《万法归一图屏》 | 宫廷纪念物无法承载全部迁徙者声音 | 图屏只能支持特定叙述位置，须与路线和多来源记录并读 |
| 当代 | 待授权的具体羌绣作品 | 作品只有展示授权，能否进入生成流程 | 创作者、来源和用途授权不完整时不得进入模型输入 |

## 统一剧情结构

1. 具名对象登场，并显示对象类别与审核或授权状态；
2. 玩家观察图像、文字、材质、位置或使用语境；
3. 出现一个不能凭直觉解决的解释冲突；
4. 玩家调用其他来源进行交叉验证；
5. 玩家决定如何记录、展陈、校勘或授权；
6. 结章生成展签、拓册、档案或权利记录，而不是改写历史结果。

## 实施状态

- 前端章节简报和任务抽屉已经统一显示 `storyAnchor`；
- 汉代、北魏、清代、当代的任务、目标和抉择已改为对象驱动；
- 唐代、元代保留现有成熟剧情，并补充统一的对象边界说明；
- 当代章暂不指定真实作品名称。取得创作者书面授权、作品信息与允许用途后，才可以替换“待授权的具体羌绣作品”；
- 清代主锚点暂选内容库中状态为 `approved` 的《万法归一图屏》，玉册与银印审核完成后可作为旁证加入。

## 验收标准

- 删除剧情锚点后，章节核心抉择应无法成立；
- 玩家进入章节简报和场景任务抽屉时都能看到同一个锚点；
- 每个抉择至少有一个选项明确保留“不知道”或“不能代表全部”的空间；
- `review` 内容不得在文案中伪装成已核验事实；
- 当代作品缺少生成授权时，流程必须允许暂停、移除或改用演示素材；
- 桌面端与移动端均不得因长文物名称发生横向溢出。
