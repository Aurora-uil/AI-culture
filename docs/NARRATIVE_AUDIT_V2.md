# 《同心千年》章节与剧情深度审视 V2

版本：2026-10-09

## 1. 立意判断

项目最有价值的方向，不是让玩家“穿越并扮演历史名人”，而是让玩家承担解释历史的责任：面对文物、图像、文本、路线和当代作品，判断哪些联系有证据，哪些联系仍需保留未知，以及在必须行动时愿意承担什么代价。

因此，六章共同主线应是：

> 边界不会切断联系。只有说明证据边界，交往、交流、交融才不会被压缩成传奇、标签或单一答案。

## 2. 本轮发现并已修复的问题

### 2.1 产品承诺与实际身份不一致

首页和史册原来使用“六段人生”，但汉、北魏、唐、清、当代的实际玩法主要是策展、档案、导览或权利校对，并非完整扮演六名历史人物。该表述会让玩家期待角色养成或历史生活模拟。

已改为“六个证据现场”和“六份证据责任”。唐章也从“鸿胪寺基层译语人”改为与实际剧情一致的“《步辇图》数字导览校对员”。

### 2.2 剧情过度强调“不能推出什么”

史料边界很清楚，但连续的否定句容易把项目变成纠错题库，削弱“交往交流交融”的正面发现。

六章阶段小结现均增加“仍可确认的联系”：先说明不能直连、不能代表或不能授权，再明确证据范围内依然能够看见的人员往来、材料互证、协作规则、多声部关系或权利连接。

### 2.3 终局选择缺少真正取舍

五章原有三个终局选项大多都显得正确，区别只剩“求真／共情／联结”数值。玩家无需权衡，也很难记住自己为什么选择。

现在每条路线都明确展示：

- 优先保护什么；
- 必须接受什么代价；
- 采用了哪些历史方法；
- 决定之后产生什么可见后果。

例如汉章“改写为长期网络物证”保护匿名参与者和长期联系，同时接受“解释成本更高、失去单一英雄叙事”的代价。

### 2.4 重大选择会被一次点击立即锁定

原通用剧情引擎在点击终局卡片时直接写入存档，操作节奏与选择重要性不匹配，也容易误触。

现在改为两步：先选择路线并阅读取舍，再点击“确认承担这条路线的后果”。

### 2.5 错误尝试没有进入叙事

原有错误答案只显示一句提示，修正后完全消失，容易让玩家把证据操作理解成普通答题。

现在错误核验会累计为“修订次数”，进入证据卷和结章记录。文案明确说明修订不是扣分，而是判断回到证据边界的过程。

## 3. 仍然存在的主要缺点

### P0：分支后果仍然太短

五章的路线差异主要集中在最后一幕与结章卡片。玩家的决定尚未改变后续任务结构、角色关系或可见展陈成果。

下一步应让终局决定至少影响三处：最终角色对白、可视化成果、史册中的跨章回声。不能只替换两句对白。

### P0：玩家仍缺少自己的声音

大多数对白由两名虚构工作人员和系统角色完成。玩家负责点击，却很少留下自己的措辞或方法备注，容易成为旁观者。

下一步可在两次阶段小结中各允许玩家写入一条“方法札记”。札记不判断对错，但会改变终局确认文案和结章记录。

### P1：五章人物关系结构过于相似

常见组合都是“追求传播或效率的人 + 守住证据的人 + 系统”。虽然职能清楚，但长期体验会形成模板感。

后续应改变冲突来源：有的来自时间压力，有的来自材料冲突，有的来自观众误读，有的来自权利人尚未回应，而不是每章都由一个谨慎角色纠正另一个角色。

### P1：挑战仍以唯一正确答案为主

前七幕大量使用正确／错误核验，适合证据教学，却不够接近叙事游戏。真实材料常存在“证据强、弱、部分支持、暂不能判断”的连续状态。

下一步应优先把关系类题目改为证据置信度或来源权重，而不是增加更多选择题。

### P1：章节顺序没有形成显性的能力递进

六章实际已经形成一条方法链：人物与网络—个案与整体—图像内外—共同与差异—单声部与多声部—知识与权利。但目录和开幕页没有把这种递进说明给玩家。

下一步应在章节目录加入“本章新增方法”和“上一章带来的方法”，让六章成为一季，而不是六个平行单元。

### P2：人物情感代价仍偏弱

现有代价多为展签吸引力、展陈空间、工期或上线时间。除了元代篇，角色之间的信任变化尚不明显。

后续可以增加职业责任与关系后果，但不能虚构真实历史人物的私人心理，也不能把在世传承人模拟为可操控角色。

### P2：历史内容仍需要专家终审

本轮只调整叙事结构、玩家身份和取舍表达，没有新增史实结论。唐代作者归属、北魏迁都表述、清代数字口径及当代权利材料仍必须由相应专家或权利人终审。

## 4. 下一轮实施顺序

1. 为五章增加可留存的“方法札记”，让玩家真正留下自己的句子。
2. 让三条终局路线分别改变可视化成果，而不只改变文字。
3. 在章节目录建立六章方法递进线。
4. 选取每章一个二元题，改造成“部分支持／直接支持／不能推出”的连续判断。
5. 完成史料与权利专家终审后，再决定是否补充更多剧情事实。
