# 《同心千年》V8 剧情游戏化视觉参考记录

参考视频：长夏（快乐版）《如果把〈甄嬛传〉做成一款游戏，叫〈梦回甄嬛传〉》  
链接：<https://www.douyin.com/video/7688632746553478435>  
观察日期：2026-09-24

## 1. 参考视频中可迁移的体验结构

1. **标题演出先建立身份**：先用全屏主题画面、环形纹样与主标题确认“进入哪段人生”，再进入操作界面。
2. **背景始终承担剧情**：选择界面没有切回普通白色弹窗，而是在虚化、压暗的剧情场景上叠加操作层。
3. **HUD 只显示当前压力**：体力、剧情提示和关键选择以少量悬浮信息出现，不把屏幕做成后台面板。
4. **选择位于下三分之一**：叙述和选择集中在下部卷面，人物与环境仍保留在上方，画面关系更接近互动影像。
5. **反馈是连续的**：标题、场景、点击、属性变化和结局画面使用相同光效、纹样与运动节奏，玩家不会感觉在不同网页间跳转。

## 2. 《同心千年》的转译原则

- 不复制参考视频的宫廷红、角色造型、书法标题、Logo、影视人物或任何具体画面。
- 保留项目自己的雾青、矿物青、古金和朱砂色系；视觉母题从“宫廷花瓣”改为“时间金线、年轮与证据印记”。
- 参考视频中的“体力”改为“剧情推进”，避免虚构生存数值。
- 参考视频中的剧情选择改为基于史料边界的历史判断；选择改变玩家记录，不改写已发生的历史结果。
- 历史原图、遗址实拍、AI 情境图必须继续展示各自来源与边界标签。

## 4. 后续制作边界

若继续提升到“人物分镜级”效果，每章还需要独立制作 3–5 张经过历史顾问审核的角色半身像与事件场景图。人物只能是游戏原创复合角色，不能使用可识别演员形象；历史人物图像也不能被描述为真实肖像或现场照片。
